# Undo a delete, and more

## files
- **Ctrl+Z undoes a delete.** Delete a file (it goes to the Trash) and press Ctrl+Z in Files to put it straight back where it came from. The message after deleting says "Ctrl+Z to undo".
- **Put Back** in the Trash still returns selected items to their folders, and now several at once.

## desktop
- Search (Ctrl+Space), Spaces (Ctrl+Left/Right), Mission Control (Ctrl+Up/F3), Alt+Tab, window snapping and Pin — see the Spaces page in the docs.
- Four themes plus your own (`~/.themes/NAME/theme.conf`); "Dark from 19:00 to 07:00".
- The top-bar speaker mutes the sounds; the Notification Centre has Dark/Light and Mute tiles.

## programs
- **Wine 10** runs Windows programs as a normal user: `sudo tpkg install wine`, then `tos-x wine program.exe`.

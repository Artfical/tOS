# Animations, and updates that reach every computer

## launcher | Desktop
- Minimising a window pours it into its app's icon in the Dock, the way the Mac's genie does;
  clicking the icon brings it back out the same way.
- Logging in: the blurred lock screen clears into the desktop instead of cutting to it.
- Menus in the menu bar fade in and drop into place when they open.
![Minimising System Settings into the Dock and bringing it back](docs/videos/genie.mp4)
![Logging in](docs/videos/login.mp4)

## settings | System Settings
- Text that is longer than its room ends in "…" instead of running under the buttons next to
  it: Software Update, Files, Notepad, Disk Utility, notifications and window titles.
- Software Update resumes a download where the connection dropped instead of failing.

## settings | Software Update
- Release notes can show videos: they play inside the notes window.

## terminal | tOS
- Builds made by GitHub could not look up any name (DNS), so Software Update said the server
  could not be found: the compiler they use dropped the addresses from every UDP checksum.
- Two programs using the disk at once no longer make both fail ("The update could not be saved
  on the disk").
- Starting up no longer prints a thousand "out of physical pages" lines before the logo.

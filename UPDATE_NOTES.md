# tpkg: info, search and which

## terminal | tpkg
- tpkg info <name> tells what a package is: its version, licence, size, whether it is installed and where, and the commands it brings (and when another package's version of one is the one that runs).
- tpkg search <text> finds packages by name or description, and tpkg which <command> says which package a command comes from.
- These three work without sudo.

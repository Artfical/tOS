## ![](icon:notepad) Notepad

![Notepad](shot:notepad.png)

Notepad edits plain text. It opens and saves files on any mounted file system, and shows **line numbers** in a gutter. For programs it **highlights syntax**: keywords, strings, numbers, comments and preprocessor lines. A file can have up to 1000 lines, with a scrollbar.

| To do this | Press |
|---|---|
| Find | Ctrl+F |
| Replace all | Ctrl+R |
| Go to a line | Ctrl+G |
| Select | Shift with the arrow keys, also across lines |
| Copy, cut, paste | Ctrl+C, Ctrl+X, Ctrl+V |

The buttons at the top are **New**, **Open** and **Save**. The status bar shows the line and column, how many lines the file has, and its size. A file you drag from Files onto Notepad opens in it.

![A file dropped onto Notepad](shot:drag_notepad.png)

## ![](icon:paint) Paint

![Paint](shot:paint.png)

Paint is a drawing program with menus and tool panels laid out like a modern one: a **Tools** panel (select, pencil, fill, text, eraser, shapes), a **Brushes** panel, an **Image** menu, a **Colours** palette and a **Layers** panel, with **zoom** at the bottom.

- Shapes (lines, rectangles, circles and others) preview while you drag, and are drawn when you let go.
- Brush sizes and outline or fill settings are in the ribbon.
- **Layers** let you draw in separate sheets and stack them.
- **Save** exports the picture as a real **PNG** file that any other program can open, through the standard file dialog.

![Saving a picture](shot:paint_save.png)

A picture you save can be opened again in Paint, in the Image Viewer, and in tFire.

## ![](icon:viewer) Image Viewer

![The Image Viewer](shot:drag_viewer.png)

The Image Viewer opens PNG pictures. It can **zoom** in and out, **fit** a picture to the window, and move around a big one with the arrow keys. **Set as Wallpaper** uses the picture as the desktop background.

## ![](icon:pdf) PDF Viewer

The PDF Viewer opens PDF files and shows their text. You can **pan** with the arrow keys or by dragging, **zoom** in and out, **fit** the page, go to the **previous** or **next page**, and search the text with Ctrl+F; pressing it again jumps to the next match, highlighted, across pages.

## ![](icon:calculator) Calculator

![The Calculator](shot:calculator.png)

The Calculator does the usual arithmetic with percent and sign keys, and has a **scientific row**: sin, cos, tan, square root, log, ln, squares and π.

## ![](icon:clock) Clock

![The Clock](shot:clock.png)

The Clock shows analogue and digital time and has a **Stopwatch** tab.

## ![](icon:sticky) Sticky Notes

Sticky Notes is a pad of eight yellow pages, one visible at a time. Click the folded corner at the bottom right to turn to the next page. Every keystroke is saved, so the notes are there at the next start, with no Save button.
